# POL

리눅스 자격증 취득을 위한 **실습 환경**과 **문제풀이 기능**을 제공하는 웹 서비스입니다.  
실습환경 구성, 문제 제공, 문제 채점 기능을 한 곳에서 제공하여 사용자는 오직 문제 학습에만 집중할 수 있습니다.

---

## 📌 프로젝트 개요
- **목적**
  - 리눅스 자격증 대비를 위한 통합 학습 플랫폼 제공
  - 실습 환경 + 문제 제공 + 채점 서비스를 한 곳에서 제공
- **특징**
  - 브라우저 기반 리눅스 터미널 실습 환경 제공
  - 문제은행 기반의 자동 채점 시스템
  - 마이페이지를 통한 학습 기록 관리
